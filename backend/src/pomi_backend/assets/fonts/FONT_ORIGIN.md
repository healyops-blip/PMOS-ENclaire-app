# Bundled Chinese font

`wqy-microhei.ttc` is **WenQuanYi Micro Hei 0.2.0-beta**, obtained from the
Debian packaging mirror maintained at
<https://github.com/anthonyfok/fonts-wqy-microhei> (upstream project:
<http://wenq.org/wqy2/index.cgi?MicroHei>).

The font is distributed here under the Apache License 2.0. The complete license
text is stored beside the font as `LICENSE_Apache2.txt`. The font is bundled in
the Python wheel so Linux deployments render CJK text without a system-font
dependency.
