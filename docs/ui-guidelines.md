# Pomi UI 规范

## 页面返回操作

- 页面层级的返回操作统一使用左上角返回箭头图标，不在页面底部放置“返回”或“返回上一步”文字按钮。
- 返回图标统一使用 `Icons.arrow_back_ios_new_rounded`，视觉尺寸为 `20px`，并放在系统安全区域内。
- 图标按钮必须提供 `tooltip` 或等价的无障碍语义，例如“返回上一步”。
- 提交或保存期间可以禁用返回图标，但应保留其位置，避免页面布局跳动。
- 弹窗中的“取消 / 确定”属于弹窗操作，不适用页面返回图标规则。

## 冷启动与首次引导布局

- 基本信息、经期情况、当前用药三个页面必须共用同一套页面骨架和间距常量，禁止在单个页面内使用临时数值单独调整留白。
- 页面内容区内边距统一为 `16px`；标题区域到首个内容控件的有效距离统一为 `24px`。
- 输入框及其错误提示预留区域组成固定高度 `76px` 的字段槽位。无错误时也必须保留同等高度，避免校验后布局跳动或重叠。
- 不同内容区块之间统一使用 `16px` 间距；标题与说明文字、标题与选项之间统一使用 `8px` 间距。
- 同组选项的横向与纵向间距统一使用 `8px`。
- 三个页面的首个内容控件、底部主按钮和返回图标必须保持相同的对齐基线。
- 如需调整冷启动页面留白，应修改共享间距常量并同步作用于三个页面，不得只修改其中一个步骤。
