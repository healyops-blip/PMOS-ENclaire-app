产品可配置项说明（化验_检测报告）

目的
- 本文专注于“可配置项”本身，帮助产品快速理解每个选项的含义、适用场景与推荐组合，便于下发定制需求。

一页总览（7 大可配置项）
1) 页面尺寸与方向：A4 竖版 / A4 横版 / A5 竖版 / A5 横版
2) 页眉风格：HEADER_01 / HEADER_02 / HEADER_03 / HEADER_04
3) 患者信息布局：PATIENT_01 / PATIENT_02 / PATIENT_03 / PATIENT_04
4) 表格样式：TABLE_01 / TABLE_02 / TABLE_03 / TABLE_04 / TABLE_05
5) 字体风格：FONT_01 / FONT_02 / FONT_03 / FONT_04
6) 信息密度：DENSITY_LOW / DENSITY_MEDIUM / DENSITY_HIGH
7) 页脚：FOOTER_01 / FOOTER_02 / FOOTER_03

详细说明与选择建议
1) 页面尺寸与方向（纸张与版心）
- A4 竖版（默认）：通用首选，信息容量与可读性平衡，适合打印与屏幕展示。
- A4 横版：横向空间更宽，适合横向表格较多或需要更宽列宽的情况。
- A5 竖版：体积更小，移动端/随访单页友好；文字与表格需更简洁。
- A5 横版：同上，但横向阅读；建议与简化的表格样式搭配。
选择建议：
- 打印/归档为主：A4 竖版/横版。
- 移动端/随访卡：A5 竖版。

2) 页眉风格（抬头信息）
- HEADER_01：医院名称居中，报告类型居中；简洁稳重，默认首选。
- HEADER_02：左侧可放 Logo，医院名居中，报告类型位于医院名下方；品牌露出更强。
- HEADER_03：医院名左对齐，右侧显示日期，下方一条粗横线；偏“公文式”，层次清晰。
- HEADER_04：医院中文名居中、英文名在下方，报告类型在右侧；适合对外文件或总部标准化展示。
选择建议：
- 强品牌/对外：HEADER_02 或 HEADER_04（需 Logo 和/或英文名）。
- 简洁规范：HEADER_01。
- 强结构层次：HEADER_03。

3) 患者信息布局（患者区排版）
- PATIENT_01：一行多列，字段横向展开；便于快速扫读。
- PATIENT_02：两行网格，整齐、容错好；字段多时推荐。
- PATIENT_03：左侧信息 + 右侧二维码位；适合扫码归档与复印件识别。
- PATIENT_04：标签式分行，阅读压力小；移动端/老年人群更友好。
选择建议：
- 字段多、需要整齐：PATIENT_02。
- 需要二维码：PATIENT_03（右侧预留二维码位）。
- 阅读友好：PATIENT_04。
- 通用：PATIENT_01。

4) 表格样式（检验结果区）
- TABLE_01：完整网格（横竖线全有），医院传统风格，清晰但略密。
- TABLE_02：仅横线，无竖线，整体更简洁，阅读轻松。
- TABLE_03：外框为主，内部少线或无横线；极简风，视觉负担最小。
- TABLE_04：分组表（如“生化指标”分组）；适合分类较多时。
- TABLE_05：左右双栏（左项目/右结果）；信息密度最高，页面利用率高。
选择建议：
- 强可读性：TABLE_02 或 TABLE_03。
- 传统严谨：TABLE_01。
- 分类清晰：TABLE_04。
- 信息量很大/纸张有限：TABLE_05。

5) 字体风格（整体气质）
- FONT_01：宋体 + 黑体（标题/页眉黑体，正文宋体）；对比强、权威感。
- FONT_02：全宋体；传统稳重、普遍兼容。
- FONT_03：黑体标题 + 宋体正文；标题突出、正文易读。
- FONT_04：无衬线（医院打印风格，小号雅黑）；现代、紧凑。
选择建议：
- 通用兼容：FONT_02 或 FONT_03。
- 视觉对比强：FONT_01。
- 现代与紧凑：FONT_04（配高密度更协调）。

6) 信息密度（字号/行距/表格紧凑度）
- DENSITY_LOW：大字号、大行距、留白多；移动端与老年人群友好。
- DENSITY_MEDIUM：默认推荐；兼顾信息量与可读性。
- DENSITY_HIGH：小字号、小行距、紧凑；适合打印与归档、信息量很大时。
选择建议：
- 移动端展示：LOW 或 MEDIUM。
- 打印归档/信息量大：HIGH。

7) 页脚（底部信息）
- FOOTER_01：检验时间 | 报告时间 | 检验者 | 审核者；医院通用必选项。
- FOOTER_02：左地址 | 中电话 | 右页码；适合对外与多页场景。
- FOOTER_03：仅检验者/审核者；极简信息。
选择建议：
- 单页/简洁：FOOTER_03。
- 有对外信息与页码：FOOTER_02。
- 通用合规：FOOTER_01。

推荐“套餐”示例（直接可用）
- 打印归档优先：A4 竖版 + HEADER_03 + PATIENT_02 + TABLE_01 + FONT_03 + DENSITY_HIGH + FOOTER_01
- 品牌强化：A4 竖版 + HEADER_02 + PATIENT_01 + TABLE_02 + FONT_01 + DENSITY_MEDIUM + FOOTER_01
- 移动端优先：A5 竖版 + HEADER_01 + PATIENT_04 + TABLE_02 + FONT_02 + DENSITY_LOW + FOOTER_03
- 极简清爽：A4 竖版 + HEADER_01 + PATIENT_04 + TABLE_03 + FONT_02 + DENSITY_MEDIUM + FOOTER_03

提交需求时请给到
- 纸张方向：A4/A5，竖/横。
- 页眉：是否放 Logo、是否显示医院英文名；报告类型标题文案。
- 患者区：选择 PATIENT_01/02/03/04；是否需要二维码位。
- 表格：TABLE_01/02/03/04/05。
- 字体：FONT_01/02/03/04。
- 密度：LOW/MEDIUM/HIGH。
- 页脚：FOOTER_01/02/03；是否需要地址/电话/页码。

一致性与展示规范（你不用操心的）
- “备注：”统一只显示一次：系统自动去掉内容开头多余的“备注：/建议：”。
- 字体与对齐按选定风格自动适配不同纸张与密度。
- 栏宽与行高会根据密度做微调，避免过密或过松。
